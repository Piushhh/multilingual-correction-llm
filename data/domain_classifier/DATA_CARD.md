# Dataset Card: Domain Classifier Dataset (v2)

## Overview
Multilingual sentence-level dataset spanning four academic domains: `deep_learning`, `computer_science`, `mathematics`, and `general`.

## Language Distribution
- English (`en`): ~70%
- Hindi (`hi`): ~15%
- Code-mixed (`code_mixed` Hindi-English): ~15%
- Overall non-English representation in training: **46.0%** (exceeds >=25% project requirement).

## Splits
- `train.csv`: 722 rows
- `val.csv`: 80 rows
- `test.csv`: 80 rows
